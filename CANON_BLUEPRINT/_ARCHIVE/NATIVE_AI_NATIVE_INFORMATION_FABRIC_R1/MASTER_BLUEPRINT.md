## 3. What is learned vs stored

### Stored structured knowledge
- facts
- relations
- contexts
- provenance
- symbols/aliases

### Learned adaptive state
- Q*/SPEAR weights
- affordance statistics
- skills
- failure prototypes
- candidate causal relations

### Observed experience
- events
- trajectories
- waveforms
- rewards

## 4. Critical boundaries

```text
FACT != WEIGHT
FACT != EPISODE
FACT != SKILL
FACT != CANDIDATE
ALIAS != IDENTITY
CORRELATION != CAUSATION
PREDICTION != TRUTH
SEARCH_INCOMPLETE != UNKNOWN
```

## 5. Native teaching principle

Prefer:

```text
state_before
+ action/opcode
+ temporal trace
+ state_after/effect
+ reward
```

over natural-language explanation.

Language may label or summarize the learned structure later.

## 6. Full Evidence principle

Full Evidence supplies verified structured domain knowledge, not language text blobs and not policy weights.

## 7. FG08 principle

Teacher input becomes candidate knowledge, never immediate fact.

## 8. Developmental principle

Self-learning learns how to act/use knowledge, while ASTRA protects legality/truth boundaries.

## 9. Hardware principle

If GEMINI/text adapter is removed, core structured reasoning should still function.

## 10. Verification principle

Every claim must be tied to causal evidence and exact artifact identity. No inherited Board Pass across new bitstreams/schema versions.
