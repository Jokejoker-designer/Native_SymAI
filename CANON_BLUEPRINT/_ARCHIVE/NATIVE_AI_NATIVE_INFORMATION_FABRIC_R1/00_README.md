# NATIVE AI — NATIVE INFORMATION FABRIC R1

**Status:** Canon-aligned architecture curriculum / cross-project standard

**Purpose:** Chuẩn hóa cách Native AI biểu diễn, nạp, lưu trữ, học, truy xuất và suy luận tri thức mà không buộc lõi phần cứng phải “nói ngôn ngữ con người”.

## 1. Ý tưởng trung tâm

Native AI không lấy ngôn ngữ tự nhiên làm ngôn ngữ mẹ đẻ của lõi. Lõi xử lý ba lớp thông tin:

1. **Binary Semantic Plane** — identity, relation, value, context, provenance, state, goal dưới dạng mã nhị phân có cấu trúc.
2. **Temporal / Wave Plane** — event, pulse, trajectory, sensor waveform, action timing, phase/frequency, reward, before/after state.
3. **Human Symbol Plane** — text, speech, aliases, labels, documents; chỉ là lớp giao tiếp/adapter với con người.

Nguyên tắc khóa:

> **Native AI learns from state, event, relation, effect, time and reward. Human language is only an adapter.**

## 2. Không phải kiến trúc neural-network thuần

- NCG/knowledge memory = sparse typed graph / structured memory.
- Q*/SPEAR = bounded learned scorers/weights where Canon allows learning.
- Skill = reusable procedural behavior.
- FEM = failure/experience memory.
- ASTRA = legality / proof / truth / status / promotion authority.
- GEMINI = language/symbol expression adapter; không phải truth authority.
