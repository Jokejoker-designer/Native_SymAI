# ARCHIVE CONFLICT INDEX

`_ARCHIVE/` is preserved source/historical evidence. It intentionally contains
statements superseded by the audited top-level R0.1 candidate. This index
prevents stale text from silently regaining authority.

Known examples:

1. `_ARCHIVE/09 MEMORY_ARCHITECTURE (Truth-Mode Update) .md` (Unicode-spaced filename)
   uses biological shorthand such as BRAM = "muscle memory", assumes fixed
   random DDR latencies, and describes a one-clock intersection comparator.
   Superseded by [§02], [§20], [§23].
2. `_ARCHIVE/NATIVE_INFORMATION_NEURONALIZATION_BLUEPRINT_R0.md` contains an
   external assessment that describes DDR as `16-bit@667 MHz`, claims only tens
   of MB/s and uses unmeasured hundreds-of-nanoseconds random latency. Superseded
   by [§23]: ~333 MHz memory clock, ~667 MT/s effective, theoretical peak
   ~1.334 GB/s; random latency/graph throughput must be measured.
3. Historical documents may contain different host-language boundaries. Current
   R0.1 architecture uses a host language adapter that may resolve aliases/intent
   to IDs but has zero answer/winner/proof/provenance authority [§01, §04].
4. Historical V1/V2/FE evidence remains valid only for the exact claims and
   artifact lineages it originally supported. It is not inherited by R0.1.

Do not edit archived files to make them appear consistent with new canon. The
conflict is part of the audit trail.
